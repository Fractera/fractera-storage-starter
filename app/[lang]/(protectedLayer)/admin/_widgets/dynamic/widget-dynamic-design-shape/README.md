# `widget-dynamic-design-shape`

Corners, borders, spacing and the app width, on the page `/<lang>/admin/design/shape` of this element's own design workshop (node step 579-1). The editor reads and writes this element's `DESIGN-CONFIG` through the door `/<lang>/admin/api/settings/design`
and the pages redraw at once, with no build.
The editors live in `../../../_components/design-editors/`; skill `use-design`.
