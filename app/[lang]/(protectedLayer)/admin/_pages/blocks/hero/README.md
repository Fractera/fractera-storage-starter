# hero — Hero

Russian title: «Герой». Order: 1.

This folder is for the blocks of the section «Hero»: First impression, clear positioning and the main offer above the fold.

It holds no code. The code of every block is in `components/blocks/`; a block belongs here when the first entry of `categories` in its card (`components/blocks/<block>.card.json`) is `hero`. It comes with `npm run blocks -- add <block>` (skill `use-blocks`). Its page: `/<lang>/admin/blocks/hero`; the preview of one block: `/<lang>/admin/blocks/hero/<block>`.
