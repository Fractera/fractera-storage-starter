# testimonials — Testimonials and social proof

Russian title: «Отзывы и социальное доказательство». Order: 8.

This folder is for the blocks of the section «Testimonials and social proof»: Confirming quality through the real experience of other people.

It holds no code. The code of every block is in `components/blocks/`; a block belongs here when the first entry of `categories` in its card (`components/blocks/<block>.card.json`) is `testimonials`. It comes with `npm run blocks -- add <block>` (skill `use-blocks`). Its page: `/<lang>/admin/blocks/testimonials`; the preview of one block: `/<lang>/admin/blocks/testimonials/<block>`.
