# showcase — Cases and portfolio

Russian title: «Кейсы и портфолио». Order: 9.

This folder is for the blocks of the section «Cases and portfolio»: Measurable results of the work, or the look of what was made.

It holds no code. The code of every block is in `components/blocks/`; a block belongs here when the first entry of `categories` in its card (`components/blocks/<block>.card.json`) is `showcase`. The design pass writes it with its card (`.claude/modes/build-design.md`). Its page: `/<lang>/admin/blocks/showcase`; the preview of one block: `/<lang>/admin/blocks/showcase/<block>`.
