# trust — Trust and logos

Russian title: «Доверие и логотипы». Order: 10.

This folder is for the blocks of the section «Trust and logos»: Reading the scale and reliability of the brand at a glance.

It holds no code. The code of every block is in `components/blocks/`; a block belongs here when the first entry of `categories` in its card (`components/blocks/<block>.card.json`) is `trust`. It comes with `npm run blocks -- add <block>` (skill `use-blocks`). Its page: `/<lang>/admin/blocks/trust`; the preview of one block: `/<lang>/admin/blocks/trust/<block>`.
