# benefits — Benefits and value

Russian title: «Преимущества и ценности». Order: 2.

This folder is for the blocks of the section «Benefits and value»: The key benefit for the user, told as claims with icons.

It holds no code. The code of every block is in `components/blocks/`; a block belongs here when the first entry of `categories` in its card (`components/blocks/<block>.card.json`) is `benefits`. It comes with `npm run blocks -- add <block>` (skill `use-blocks`). Its page: `/<lang>/admin/blocks/benefits`; the preview of one block: `/<lang>/admin/blocks/benefits/<block>`.
