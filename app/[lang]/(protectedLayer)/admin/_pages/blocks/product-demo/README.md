# product-demo — Product in action

Russian title: «Продукт в действии». Order: 4.

This folder is for the blocks of the section «Product in action»: Showing the interface, the physical product or a key feature.

It holds no code. The code of every block is in `components/blocks/`; a block belongs here when the first entry of `categories` in its card (`components/blocks/<block>.card.json`) is `product-demo`. The design pass writes it with its card (`.claude/modes/build-design.md`). Its page: `/<lang>/admin/blocks/product-demo`; the preview of one block: `/<lang>/admin/blocks/product-demo/<block>`.
