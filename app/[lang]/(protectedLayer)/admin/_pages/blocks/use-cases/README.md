# use-cases — Use cases

Russian title: «Сценарии использования». Order: 5.

This folder is for the blocks of the section «Use cases»: Segmenting the audience: how the product solves the tasks of a role or an industry.

It holds no code. The code of every block is in `components/blocks/`; a block belongs here when the first entry of `categories` in its card (`components/blocks/<block>.card.json`) is `use-cases`. The design pass writes it with its card (`.claude/modes/build-design.md`). Its page: `/<lang>/admin/blocks/use-cases`; the preview of one block: `/<lang>/admin/blocks/use-cases/<block>`.
