# comparison — Comparison

Russian title: «Сравнение». Order: 6.

This folder is for the blocks of the section «Comparison»: Setting the product apart from competitors or from the old way of solving the problem.

It holds no code. The code of every block is in `components/blocks/`; a block belongs here when the first entry of `categories` in its card (`components/blocks/<block>.card.json`) is `comparison`. It comes with `npm run blocks -- add <block>` (skill `use-blocks`). Its page: `/<lang>/admin/blocks/comparison`; the preview of one block: `/<lang>/admin/blocks/comparison/<block>`.
