# `prototypes/_components/`

Components of the design prototypes branch (step 711-4): `prototype-page.tsx` — the child route with the prototype's own token copy (the
shared page renderer inside a `data-prototype` wrapper, `lib/prototypes.ts`) with the prototype's own sections; `prototype-sections.ts` —
every prototype's own set by its id (step 717-3), generated by `npm run prototype` and by the build (`node scripts/prototype.mjs index`
in prebuild), never edited by hand.
