# `widget-dynamic-prototypes-list`

The list of this element's design prototypes on `/<lang>/prototypes` (node step 711-4): each with its skill, the page it came from, its
references, its status and a link. Reads `lib/prototypes.ts` at request time — a new prototype shows without a build. Build cost: none
beyond the branch; caching: the branch revalidates every 60 s.
