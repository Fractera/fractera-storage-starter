# widget-static-storage-landing — the object storage's landing (node step 650-4)

The home page of the object storage, drawn after the Stripe sample (`widget-static-stripe-landing`, step 573-7) like the other memory
elements: the page is `bare`, this widget draws it from the items of the page data, a part is `section-head` and the items up to the
next, its view chosen by its `id` (`route` beside the hero, `solves`, `spaces` with `section-access-map`, `connect`, `hood`, `credits`).
Words only in the data; the machine copy comes from the items, `markdown.ts` returns nothing. Claims checked against README; the
section «Whose memory it is» says plainly that the deep memory decides whose file it is and the library itself is shared.
