# Cancelled — what was dropped, by whose word, and what replaced it

A decision that is gone still matters: without this file the next session rebuilds the dropped thing from memory, as news.

- A line is added the day the person cancels a step, a substep, a rule or a meaning of a term, or asks to roll back built work.
- Every line names what replaced it — or says that nothing did.
- The rule or text that was cancelled is not deleted silently elsewhere: in `CLAUDE.md` or a skill it is removed in the same commit
  that adds the line here.

Format, one line per item:

```
- <date> — <what was cancelled> · the person: «<their words>» · replaced by: <what, or «nothing»> · <commit>
```
